# マイナビ転職提案自動化ツール

採用情報から最適な提案を自動生成するWebアプリケーション。

## 🎯 機能

- **自動提案生成**: 企業情報から難易度を計算し、最適な企画を自動選定
- **複数プラン提示**: 採用確度優先プランと予算内プランを同時提示
- **他社事例表示**: 類似企業の掲載実績（PV数・応募数）を自動抽出
- **PDF提案書出力**: 生成された提案を営業資料として出力
- **管理画面**: 料金表、キャンペーン、事例データをExcelで一括管理
- **難易度バイアス**: 都道府県別・職種別の有効求人倍率を反映

## 📊 提案ロジック

### 難易度スコア計算
- 採用ターゲット（新卒～スペシャリスト）
- 採用人数
- 職種別難易度
- 採用時期
- 勤務地別難易度（都道府県別有効求人倍率）
- 業種別難易度

### 企画選定
- 職種別掲載案件数分布を参考
- 難易度スコアに基づく企画選定
- 予算制約を考慮した下位プランへの自動調整

## 🚀 クイックスタート

### 必要な環境
- Node.js 18以上
- pnpm 10以上

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/あなたのユーザー名/mynavi-proposal-tool.git
cd mynavi-proposal-tool

# 依存関係をインストール
pnpm install

# 開発サーバーを起動
pnpm dev
